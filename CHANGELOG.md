# История изменений

## 0.7.0 (в работе)
- Запись матчей: программа сама сохраняет все данные GSI каждого матча в `recordings/`
  (сжатый JSON Lines, ~1–2 МБ на матч, последние 50). Токен, SteamID и ник вырезаются.
  Запись читается и во время матча, и после сбоя программы. ☰ → «Записывать матчи».
- `tools/replay.py`: лента советов по записанному матчу, проверка на нарушения (совет купить
  купленное, «купить сейчас» дороже золота, продать несуществующий предмет, падение советника,
  спам тренера), проигрывание записи в запущенную программу.
- Шаблоны issue просят приложить запись матча.
- Совет больше не прыгает с предмета на предмет. Выбранная цель держится, пока предмет
  не собран; смена — только по понятной причине, и она показывается в окне и голосом
  («BKB собран — следующий: Blink Dagger», «Вы купили Ogre Axe — проще закончить BKB»).
  Веса стадий меняются плавно, без скачка на 10:00 и 30:00. На модели «послушного игрока»
  (9 сценариев) скачков было 7, стало 0.
- Собранные предметы вроде Skull Basher больше не выпадают из советов как «детали» Abyssal Blade.
- Против врагов с контролем BKB больше не советуется на первой минуте раньше ботинок.
- Понятный список покупок: одна главная фраза («Купите сейчас: Mithril Hammer» /
  «Копите на Mithril Hammer: не хватает 740»), части с отметками ✓ есть / ▶ купите сейчас /
  ○ позже, рецепт последним с пояснением. Голос подсказывает, когда хватило на часть.
- `tools/replay.py` ловит «качели»: возврат совета к прежнему предмету без покупок.
- Ядро отдельно от окна: `coach/engine.py` решает, что советовать, что сказать тренеру и
  голосу, когда матч окончен. Окно только показывает. `tools/replay.py` идёт через то же
  ядро, так что записи проверяют программу целиком; `--voice` показывает фразы голоса.
  Это подготовка к новому интерфейсу на PySide6. Без интернета и кэша `replay` пишет понятное
  сообщение вместо трассировки.
- Строка с текущей версией в начале README. `tools/bump_version.py` меняет версию в коде,
  README и CHANGELOG разом, а тест не пропустит, если они разошлись.

## 0.6.1
- Исправлены тесты на Windows: файлы с русским текстом записывались без явной кодировки
  (на Windows по умолчанию cp1252, а не UTF-8).
- CI теперь падает на любом чтении или записи файла без явной кодировки — даже на Linux.
- Оформление репозитория: бейджи, превью для соцсетей, CONTRIBUTING, шаблоны issue и PR.

## 0.6.0
- Код приведён к PEP 8: строки до 79 символов, автоформатирование `ruff format`, отсортированные
  импорты, аннотации типов в ядре. Проверки `ruff`, `flake8` и `mypy` проходят без замечаний;
  настройки — в `pyproject.toml` и `.flake8`. В GitHub Actions добавлена проверка стиля и типов.
- Структура: `ui.py` разделён на главное окно, `dialogs.py` и `theme.py`; разбор матча разбит
  на функции по разделам; скрипты PowerShell вынесены в отдельный модуль; тесты больше
  не правят `sys.path`, общие заготовки лежат в `tests/helpers.py`.
- История матчей (☰ → «История матчей») и раздел «Прогресс» в разборе: сравнение с вашими
  прошлыми матчами. В журнал матча записывается победа или поражение.
- Проверка подключения (☰ → «Проверка подключения»): сервер, GSI-конфиг, данные от игры,
  OpenDota, русский голос — с подсказкой, что исправить.
- Напоминания: саппорту — когда в лавке появился Observer Ward; кору в лейте — что выкуп
  на перезарядке.
- Ошибки обработчика GSI теперь пишутся в `coach.log`, а не теряются.

## 0.5.0
- Разбор после матча: ключевые предметы и на сколько позже, чем хватало золота, их купили;
  «простой» золота; ласт-хиты к 10-й минуте; смерти подряд; сравнение золота, опыта и добиваний
  с другими игроками на герое (OpenDota benchmarks); 2–3 совета на следующий матч.
  Окно открывается само, разборы сохраняются в `match_logs/`.
- Иконки предметов, как в магазине Dota (CDN Steam, кэш на диске).
- Журнал ошибок `coach.log` вместо тихих падений; версия в заголовке окна.
- Оформление для GitHub: `.gitignore`, лицензия MIT, автотесты в GitHub Actions, шаблон issue.

## 0.4.0

  (OneCore) с запасным SAPI, выбор голоса и скорости, очередь фраз с приоритетами.
- Советы тренера по стадиям матча и таймингам 7.41 (руны, стаки, переход в мид-гейм и лейт),
  отдельно для кора и саппорта; советы после первой смерти и по ласт-хитам к 10 минуте.
