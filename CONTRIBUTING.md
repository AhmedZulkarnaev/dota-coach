# Как помочь проекту

Спасибо, что заглянули! Ниже — с чего начать, от самого простого к сложному.

## Без программирования

- **Сообщить о странном совете.** Сыграйте матч и [создайте issue](../../issues/new/choose): герой, время матча, что посоветовала программа и что было бы правильнее. Приложите запись матча из папки `recordings/` (файл `.jsonl.gz`, личных данных в нём нет): по ней можно воспроизвести всю игру и увидеть, что программа советовала.
Все правила — обычные JSON-файлы в `coach/data/`. В начале каждого есть пояснение `_about`. После правки запустите `python tools/check_rules.py`: он покажет ошибку с точным местом.

- **Поправить произношение.** Если голос читает название криво, добавьте слово в `words` в `coach/data/speech_ru.json`.
- **Советы тренера по стадиям** — `coach/data/coach_tips.json`: текст и время в секундах.
- **Советы по способностям для героя** — `coach/data/abilities.json`: раздел с именем героя, внутри внутреннее имя способности (как его присылает Dota), совет и теги. Пример — раздел Ursa.
- **Объяснение для предмета** — `why` в `coach/data/items.json`.
- **Что покупать против врагов** — `coach/data/enemies.json`: признаки героев и правила.
- **Сленговые имена героев** для поиска врагов — `coach/data/heroes_ru.json`.

Хотите сначала попробовать у себя, не меняя встроенные файлы? Положите правку в `rules/` рядом с `main.py` — как это работает, описано в README, раздел «Свои правила».

## Разработка

```
git clone https://github.com/AhmedZulkarnaev/dota-coach.git
cd dota-coach
pip install -r requirements-dev.txt   # только ruff и mypy, самой программе пакеты не нужны

python -m unittest -v      # тесты: без Dota и без интернета
ruff check .               # PEP 8
ruff format .              # автоформатирование
mypy                       # типы
python main.py             # запуск; тестовый матч: python tools/simulate_gsi.py --speed 5
python tools/bump_version.py 0.7.0.dev5   # смена версии везде сразу
python tools/check_rules.py               # проверка правил в coach/data
```

Перед pull request убедитесь, что все четыре проверки проходят: на GitHub они запускаются автоматически.

## Правила

- **Только Game State Integration.** Никакого чтения памяти игры, внедрения в клиент, нажатий клавиш за игрока и показа того, что игрок не видит сам. Такие изменения не будут приняты: аккаунты пользователей не должны оказаться под угрозой.
- **Без сторонних зависимостей** у самой программы — её запускают новички двойным кликом по `start.bat`.
- Новая логика — с тестом. Логика живёт в ядре `coach/engine.py`, отдельно от окна, поэтому тестируется без Windows. В `coach/ui.py` — только отрисовка.
- Версию не правьте руками: `python tools/bump_version.py <версия>` меняет её в коде, README и CHANGELOG разом.
- Тексты для пользователя — по-русски, коротко и понятно новичку.
