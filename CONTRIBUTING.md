# Как помочь проекту

Спасибо, что заглянули! Ниже — с чего начать, от самого простого к сложному.

## Без программирования

- **Сообщить о странном совете.** Сыграйте матч и [создайте issue](../../issues/new/choose): герой, время матча, что посоветовала программа и что было бы правильнее. Приложите `match_logs/match_<номер>.json` — по нему видно всю ситуацию.
- **Поправить произношение.** Если голос читает название криво, добавьте слово в словарь `WORDS` в `coach/speech_ru.py`.
- **Советы тренера по стадиям** лежат списком `TIPS` в `coach/match_coach.py` — обычный текст с временем.

## Простые задачи в коде

- **Советы по способностям для героя.** В `coach/abilities.py`, словарь `TIPS`: ключ — внутреннее имя способности (как его присылает Dota), значение — короткий совет и теги. Пример — блок Ursa.
- **Объяснение для предмета.** Словарь `WHY` в `coach/explanations.py`.
- **Сленговые имена героев** для поиска врагов — `coach/heroes_ru.py`.

## Разработка

```
git clone https://github.com/AhmedZulkarnaev/dota-coach.git
cd dota-coach
pip install -r requirements-dev.txt   # только ruff и mypy, самой программе пакеты не нужны

python -m unittest -v      # тесты: без Dota и без интернета
ruff check .               # PEP 8
ruff format .              # автоформатирование
mypy                       # типы
python main.py             # запуск; тестовый матч: python tools/simulate_gsi.py --speed 5
```

Перед pull request убедитесь, что все четыре проверки проходят: на GitHub они запускаются автоматически.

## Правила

- **Только Game State Integration.** Никакого чтения памяти игры, внедрения в клиент, нажатий клавиш за игрока и показа того, что игрок не видит сам. Такие изменения не будут приняты: аккаунты пользователей не должны оказаться под угрозой.
- **Без сторонних зависимостей** у самой программы — её запускают новички двойным кликом по `start.bat`.
- Новая логика — с тестом. Логика отделена от окна, поэтому тестируется без Windows.
- Тексты для пользователя — по-русски, коротко и понятно новичку.
