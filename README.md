# Dota Coach — тренер для новичков в Dota 2

Программа следит за вашим матчем в реальном времени и подсказывает:
- **какой предмет купить следующим**, сколько золота не хватает, что можно купить уже сейчас и **почему** этот предмет нужен;
- **что делать на этой стадии игры**: «игра началась — добивайте крипов», «фармите лес», «скоро руны»;
- **когда использовать способности** героя;
- после матча — **разбор**: что купили позже, чем могли, где простаивало золото, как вы выглядите на фоне других игроков на этом герое.

Всё на русском, с озвучкой. Windows 10/11, Python 3.10+, без сторонних библиотек.

> *English:* a real-time Dota 2 coach for beginners (Russian UI). It uses only Valve's official Game State Integration, suggests the next item based on OpenDota statistics, gives stage-by-stage tips with Windows text-to-speech, and builds a post-match review. No memory reading, no client injection.

*Dota Coach — неофициальный проект, не связан с Valve. Dota 2 — товарный знак Valve Corporation.*

## Безопасность аккаунта

- Используется только **Game State Integration (GSI)** — официальный механизм Valve. Через него работают Overwolf-приложения и стрим-оверлеи.
- Программа **не читает память игры, не встраивается в клиент и не нажимает клавиши**. Dota сама отправляет JSON на локальный адрес `127.0.0.1`. Снаружи этот адрес недоступен, а данные без секретного токена из конфига не принимаются.
- Программа видит только то, что видите вы сами: своего героя, золото, предметы и время матча. Предметы врагов GSI не передаёт, поэтому героев врага вы вводите вручную.

## Установка (один раз, ~5 минут)

1. Установите **Python 3.10 или новее** с [python.org/downloads](https://www.python.org/downloads/).
   В установщике поставьте галочку **«Add python.exe to PATH»**. Компонент «tcl/tk» оставьте включённым (он включён по умолчанию).
2. Скачайте программу (на GitHub: зелёная кнопка **Code → Download ZIP**) и распакуйте в любую папку, например `C:\DotaCoach`.
3. Запустите **`start.bat`**. Других библиотек ставить не нужно: программа использует только стандартный Python.
4. При первом запуске программа предложит **установить GSI-конфиг**. Нажмите «Да». Папка Dota находится автоматически через Steam. Если не нашлась, укажите папку `...\steamapps\common\dota 2 beta`.
5. Добавьте параметр запуска Dota 2:
   Steam → Библиотека → правый клик по Dota 2 → **Свойства** → «Общие» → **Параметры запуска** → впишите `-gamestateintegration`.
6. Перезапустите Dota 2. Вверху окна программы должно загореться **● Dota подключена**.

При первом запуске нужен интернет: программа скачает базу предметов и героев (около 1 МБ). Дальше она работает по кэшу.

### Проверка без игры
Запустите `start.bat`, затем `simulate.bat`. Симулятор «сыграет» ускоренный матч на Урсе, и вы увидите, как меняются подсказки. Чтобы спокойно послушать советы тренера, запустите медленнее: `simulate.bat --speed 5`.

## Как пользоваться

| Что видно в окне | Значение |
|---|---|
| Герой, время, стадия | Старт / Лайнинг 0–10 / Мид-гейм 10–30 / Лейт 30+ |
| 💬 Тренер | Совет по стадии матча: «игра началась — добивайте крипов», «фармите лес», «скоро руны» |
| **Следующий предмет** и полоса | Цель и сколько уже собрано: компоненты + текущее золото |
| Не хватает / «Золота хватает» | Разница между золотом и оставшейся стоимостью |
| Можно купить уже сейчас | Самые дорогие компоненты, на которые хватает денег. Рецепт — в последнюю очередь |
| ⚠ Красная плашка | Нет места: что использовать, продать (в том числе из рюкзака) или переложить в рюкзак |
| Что даёт | Кратко: смысл предмета, его кнопка и основные статы |
| Почему сейчас | Место предмета в популярности на вашем герое на этой стадии, начатая сборка, враги |
| ⚠ Против врагов | Ситуативные предметы (BKB, Monkey King Bar, Spirit Vessel…) |
| • Напоминания | Нет TP, нет ботинок, копите на выкуп, «вы мертвы — закупитесь» |
| Дальше по плану | Следующие 2–3 предмета |
| » Голубые подсказки | Прямо сейчас: «мало здоровья — нажмите Enrage», «ульт готов», «мало маны» |
| Способности | Внизу: каждая способность героя, готова ли она и когда её лучше использовать |

- **Враги**: в начале матча нажмите кнопку «Враги» и введите 5 героев. Искать можно по-английски, по-русски и сленгом: «па», «ам», «сф», «лион». При новом матче список очищается сам.
- **Режим окна** (кнопка ☰ или правый клик):
  - *Обычное окно* — удобно на **втором мониторе**.
  - *Оверлей* — окно без рамки поверх игры. Перетаскивается мышью, размер меняется за уголок справа внизу. Для оверлея поставьте в Dota *Настройки → Видео → «Окно без рамки»*.
  - Непрозрачность от 50 до 100%, «Компактно» скрывает объяснения.
- **Озвучка** (🔊): программа говорит советы тренера, следующий предмет, «хватает золота» и «мало здоровья». Подробнее — в разделе «Голос» ниже.
- **Моя роль**: по умолчанию определяется по ролям героя. Если играете героя не в своей обычной роли (например, Лиона в миду), выберите «Кор» или «Саппорт» вручную.

## Откуда знания о сборках и как они обновляются

Источник — **OpenDota API**, бесплатный и без ключа:

| Запрос | Что даёт |
|---|---|
| `/constants/items` | Цены, компоненты, характеристики всех предметов (берутся из файлов игры) |
| `/constants/heroes` | Герои и их роли (Carry, Support, Disabler, Nuker…) |
| `/heroes/{id}/itemPopularity` | Что покупают на герое по стадиям: старт, 0–10, 10–25, 25+ мин |
| `/constants/patch` | Номер патча, чтобы сбросить кэш при обновлении игры |

- Ничего не зашито в код. При запуске программа сверяет номер патча: если он новый, кэш перекачивается полностью. Иначе данные обновляются раз в 3 дня, чтобы ловить мелкие патчи вроде «7.41d». Кнопка ☰ → «Обновить данные» скачивает всё заново.
- Сеть никогда не тормозит подсказку: совет считается из локального кэша примерно за **1 мс**, а полный цикл «данные игры → подсказка» занимает меньше 0,5 с.
- **Важно:** популярность предметов в OpenDota считается по матчам сильных игроков. Это хорошие сборки, но не всегда самые простые.
- **Альтернатива — STRATZ API**: даёт статистику по рангу (можно смотреть сборки на вашем уровне) и винрейты предметов. Нужен бесплатный токен и GraphQL-запросы. Хорошее улучшение для следующей версии: в коде это один новый класс рядом с `data_store.py`.

## Почему правила, а не языковая модель

Выбрана схема «**жёсткие правила + статистика**»:
- мгновенно, без интернета во время матча, бесплатно;
- предсказуемо: одинаковая ситуация даёт одинаковый совет, и его легко проверить;
- объяснения написаны вручную для 110+ ключевых предметов. Для остальных программа сама собирает описание из характеристик предмета.

ИИ можно добавить позже **только для текста объяснений**, а предмет по-прежнему будут выбирать правила. Для этого нужно заменить одну функцию `explain()` в `coach/explanations.py` и сделать фолбэк на шаблон, если модель не ответила за 1–1,5 с.

## Как программа выбирает предмет

1. Берёт популярные предметы героя для текущей стадии (вес 1.0), следующей (0.6, чтобы копить заранее) и предыдущей (0.5, на случай отставания).
2. Отбрасывает уже купленное и всё, из чего оно собрано, расходники, нейтральные предметы, вторые ботинки и одиночные компоненты: они появятся в плане сборки.
3. Даёт сильный бонус **начатой сборке**: если у вас лежит Ogre Axe, советом будет BKB, а не новый предмет.
4. Учитывает врагов: 3+ героя с контролем → BKB для кора или Glimmer Cape для саппорта; уклонение → Monkey King Bar; лечение → Spirit Vessel; иллюзии → Maelstrom; невидимки → напоминание про Dust и Sentry.
5. Раскладывает цель на недостающие части с учётом того, что уже есть: в инвентаре, рюкзаке и тайнике.
6. Следит за **местом в инвентаре** (6 активных слотов; рюкзак их не занимает, тайник считается вместе с инвентарём):
   - если предмет собирается из того, что уже лежит в слотах, место не нужно;
   - если места нет, подсказывает, что сделать: «используйте Tango», «поставьте варды», «продайте Quelling Blade (+50)», «переложите в рюкзак»; ботинки не трогает;
   - когда занят и рюкзак, первым продаёт мусор оттуда (он всё равно не работает), чтобы освободить место;
   - если частям предмета некуда лечь, не советует покупать их по одной: они бы остались в тайнике без пользы;
   - не советует предмет, ради которого пришлось бы выкинуть почти такую же ценную вещь;
   - когда все 6 слотов заняты сильными предметами, советует то, что слот не занимает (Aghanim's Shard), или копить на выкуп.

## Голос

- Используются голоса Windows, интернет не нужен. В первую очередь — современные голоса Windows 10/11 («Microsoft Irina», «Microsoft Pavel»), они звучат заметно лучше старых.
- **Нужен русский голос**: *Параметры → Время и язык → Речь → «Добавить голоса» → Русский*, затем перезапустите программу. Без русского голоса программа молчит (русский текст английским голосом звучит как каша) и показывает эту подсказку.
- **Произношение**: английские названия на экране остаются как в игре, а для голоса заменяются русским звучанием: Black King Bar → «блэк кинг бар», Eye of Skadi → «ай оф скади», TP → «тэ-пэ». Словарь — в `coach/speech_ru.py`. Незнакомые слова читаются по правилам английского чтения.
- **Меню ☰ → Голос**: «Проверить голос», скорость (медленно / обычно / быстрее), выбор голоса (Ирина, Павел…).
- Фразы встают в очередь по важности и не обрывают друг друга. «Мало здоровья» и смена стадии звучат первыми. Устаревшая фраза, которая ждала дольше 25 секунд, пропускается.

## Советы тренера по стадиям

Не постоянный поток, а разовые советы в нужный момент — примерно 15–20 за матч, чаще всего в первые 10 минут. Между советами минимум 25 секунд. Советы разные для кора и саппорта:

| Время | Кор | Саппорт |
|---|---|---|
| до горна | Купите старт и идите на линию | то же |
| 0:00 | Добивайте крипов — это ваше золото | Помогайте керри, не забирайте добивания, поставьте вард |
| 2:15 / 2:30 | Денайте своих крипов | Пул из малого лагеря |
| 3:40, 7:40 | Скоро руны богатства (каждые 4 мин) | то же |
| с 4:45 | — | Стак лагеря на 53-й секунде (каждые 3 мин до 15:00) |
| 5:30 | Между волнами фармите лес | — |
| 5:45 | Первая сильная руна в 6:00 | то же |
| 10:00 | Линия закончилась: волна → лес → волна | Держитесь с командой, варды, Smoke |
| 10–11 мин | Итог по ласт-хитам (цель — 45+) | — |
| 13, 16, 20, 25 мин | Группа, безопасность, Рошан, цена смерти | то же |
| 30:00, 40:00 | Лейт: выкуп, ходить группой | Лейт: держаться за корами, Gem |

Плюс советы по ситуации: после первой смерти (разбор, почему так вышло) и если вы часто умираете на линии.

- **Меню ☰ → Советы тренера**: «Все», «Только главные» (смена стадий и разбор ошибок) или «Выключить».
- Если программу запустили посреди матча, старые советы не вываливаются разом: пропущенное просто пропускается.
- Тайминги проверены для патча 7.41. Если Valve их поменяет, список можно поправить без программирования: создайте рядом с `main.py` файл `coach_tips.json` в формате списка `TIPS` из `coach/match_coach.py`.

## Подсказки по способностям

- Список способностей, уровень, перезарядку и готовность присылает сама Dota через GSI.
- Для 21 популярного героя (Ursa, Juggernaut, Phantom Assassin, Wraith King, Sniper, Drow Ranger, Lion, Crystal Maiden, Pudge, Axe, Sven, Lina, Zeus, Witch Doctor, Dragon Knight, Bristleback, Earthshaker, Faceless Void, Anti-Mage, Shadow Shaman, Legion Commander, Viper, Ogre Magi) советы написаны вручную в `coach/abilities.py`, словарь `TIPS`.
- Для остальных героев совет собирается автоматически по описанию способности из OpenDota (оглушение, замедление, урон, побег, защита, лечение). Он более общий. Добавить своего героя — пара строк в `TIPS`.

## Разбор после матча

Когда матч заканчивается, программа сама открывает разбор и сохраняет его в папку `match_logs/` (меню ☰ → «Разбор последнего матча»):
- итог: KDA, добивания, золото и опыт в минуту;
- **сравнение с другими игроками на этом герое** (OpenDota): «золото в минуту 520 — лучше, чем примерно у 60% игроков»;
- линия: добивания к 10-й минуте (цель 45+), смерти до 10-й минуты;
- ключевые предметы со временем покупки и пометкой, если золота на предмет хватало заметно раньше;
- «простой» золота: сколько минут вы держали деньги на следующий предмет и не покупали;
- смерти подряд — признак того, что вы возвращались в ту же драку;
- 2–3 конкретных совета на следующий матч.

## Ограничения

- Предметы **на курьере** GSI не показывает. Они появятся в расчёте, когда курьер их доставит.
- Режим зрителя и просмотр реплеев не поддерживаются (там другой формат данных).
- Порт `47113`. Если он занят, поменяйте `port` в `settings.json` и заново установите GSI-конфиг через меню.

## Что дальше (следующие версии)

Заделы уже есть в коде:
- **Тайминги** (руны, Рошан, стаки, варды). Время матча уже приходит. Интервалы событий лучше держать в отдельном JSON-файле, потому что они меняются от патча к патчу.
- **Прокачка способностей**: подсказки «когда использовать» уже есть. Порядок прокачки можно брать из популярных билдов (STRATZ).
- **Разбор матча глубже**: сравнение таймингов предметов со средними по герою, история прогресса за несколько матчей.
- **Сборки под ваш ранг** через STRATZ API (нужен бесплатный токен).

## Разработка

```
python -m unittest discover tests -v     # тесты движка, голоса, советов и разбора (без Dota и без интернета)
python tools/simulate_gsi.py --speed 5   # тестовый матч без Dota (программа должна быть запущена)
```

- Сторонних зависимостей нет — только стандартная библиотека Python.
- Тесты запускаются автоматически на GitHub (Windows и Linux) при каждом push — см. `.github/workflows/tests.yml`.
- Файл `settings.json` с секретным токеном GSI в репозиторий не попадает (`.gitignore`).
- История изменений — в `CHANGELOG.md`.

## Если что-то не работает

- **«нет данных от Dota»**: проверьте параметр `-gamestateintegration` и наличие файла `...\dota 2 beta\game\dota\cfg\gamestate_integration\gamestate_integration_dotacoach.cfg`. Перезапустите Dota.
- **«Нет связи с OpenDota»**: нет интернета или сайт временно недоступен. Программа работает по кэшу. В самый первый раз интернет обязателен.
- **Окно не поверх игры**: включите в Dota «Окно без рамки». В полноэкранном режиме поверх игры не может быть ни одно окно.
- **Окно открывается и сразу закрывается** или что-то ведёт себя странно: загляните в файл `coach.log` в папке программы — туда записываются все ошибки. Его же стоит приложить, если будете сообщать об ошибке (issue на GitHub).
